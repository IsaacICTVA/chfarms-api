📝 Daily log — how John enters every day

  1. John taps the app link on his phone (or browser)
  2. Selects John from the user list, enters PIN 2001
  3. Goes to Daily Log Entry in the menu
  4. Fills: Date, Batch (19a / 19b / 20a), Mortality count, Feed bags used
  5. Taps Save Log Entry
  6. If offline — entry shows "Queued" and saves locally. When John (or Iyanu) reconnects, the top bar shows a pending count. Iyanu taps ↑ Sync to push to Google Sheet tab 03_Broiler Live Log
✅ Each daily entry writes one row to 03_Broiler Live Log automatically — no copy-paste needed.

🧾 Buyer Quote Agent — generate & download PDF

  1. Go to Buyer Quote Agent in the menu
  2. Enter customer name, phone, product type (Broiler Meat / Pullet Eggs / Medium Eggs), quantity
  3. Prices auto-fill: Broiler ₦4,500/kg · Pullet Eggs ₦3,800/crate · Medium Eggs ₦5,100/crate
  4. Tap Check stock & generate quote
  5. System checks live bird count and processing schedule:
    → If stock available = CONFIRMED QUOTE
    → If not yet processed = PROJECTION QUOTE with ETA date
  6. Tap ⬇ Download PDF — full A4 branded PDF with quote terms
  7. Quote automatically writes to Sheet tab 07_Customer_Order_Quote

🚀 Getting this system online (Render)

This dashboard connects to a Python backend. You need to deploy it once to get a permanent link anyone on your farm can use:

  1. Create a free account at github.com and a new repository called chfarms-api
  2. Upload app.py and requirements.txt (from the ZIP file delivered with this)
  3. Create a free account at render.com → New Web Service → connect your GitHub repo
  4. Build command: pip install -r requirements.txt · Start: gunicorn app:app
  5. Add env variable: GOOGLE_SHEET_ID = 1ajWKs867tssC1DqY-miGiLG61eNZIKoZCpv5x-18LvY
  6. Copy your Render URL → open this file in a text editor → find let API_URL → replace → save
✅ Until deployed, the system works in offline mode — all data queues locally. Enter the API URL in Settings → Deploy when ready.
